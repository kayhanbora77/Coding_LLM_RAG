# AI Skills Directory

This directory organizes the artificial intelligence and machine learning capabilities implemented across the RAG project by skill type and functionality.

## Skill Categories

### General Development Skills

### 1. [Commit Message Generator](./COMMIT_MESSAGE_GENERATOR.md)
- Generate conventional commit messages
- Follow standard formatting practices
- Automate Git history organization

### 2. [PR Review Assistant](./PR_REVIEW_ASSISTANT.md)
- Automated pull request review
- Code quality assessment
- Best practice identification

### RAG Project Specific Skills

### 3. [Natural Language Understanding](./natural_language_understanding.md)
- Text processing and analysis
- Semantic similarity calculations
- Language model integration

### 4. [Information Retrieval](./information_retrieval.md)
- Document embedding and indexing
- Vector database operations
- Similarity search algorithms

### 5. [Query Processing](./query_processing.md)
- Query expansion and transformation
- Multi-query generation
- RAG-Fusion techniques

### 6. [Reasoning & Inference](./reasoning_inference.md)
- Task decomposition
- Multi-step question answering
- Logical reasoning chains

### 7. [Ranking & Fusion](./ranking_fusion.md)
- Reciprocal Rank Fusion (RRF)
- Result reranking algorithms
- Multi-list aggregation

### 8. [Text Generation](./text_generation.md)
- Context-aware generation
- Prompt engineering
- Response synthesis

## AI Models & Technologies

### Embedding Models
- Hugging Face BGE models
- Semantic similarity computation
- Vector space representations

### Language Models
- Groq API integration
- Llama 3.1 models
- Temperature-controlled generation

### Vector Databases
- ChromaDB for similarity search
- Indexing and retrieval optimization
- Persistent storage solutions

## Implementation Levels

Each skill is implemented across different levels of sophistication:

- **Basic**: Fundamental implementation in llm_rag_v1
- **Enhanced**: Improved techniques in llm_rag_v2-v3
- **Advanced**: Sophisticated methods in llm_rag_v4-v5
